# Документация проекта
## Описание базового синтаксиса записи и форматирования
1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.
- Секретные данные (логины, пароли, API-токены) вынесены в безопасный файл `.env` и не хранятся в коде.

---

## Режимы запуска тестов с формированием отчета Allure

### 1. Запуск всех тестов вместе (UI + API)
Запускает полную проверку проекта:
```bash
pytest diploma/ --alluredir=./allure-results -v
```

### 2. Запуск только UI-тестов
Запускает только тесты, взаимодействующие с браузером Chrome:
```bash
pytest diploma/ -m ui --alluredir=./allure-results -v
```

### 3. Запуск только API-тестов
Запускает тесты без открытия веб-браузера:
```bash
pytest diploma/ -m api --alluredir=./allure-results -v
```

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов в любом из режимов, чтобы просмотреть интерактивный отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```
   Эта команда запустит локальный сервер и автоматически откроет отчет в веб-браузере.

2. В отчете Allure вы увидите структуру тестов и детальные шаги их выполнения:

   - **Название теста**: `Авторизация на сайте YouGile`.
   - **Описание теста**: `Тест проверяет авторизацию по email и паролю с использованием сквозной сессии`.
   - **Шаги теста**:
     - Открыть страницу сайта.
     - Выполнить автоматический вход.
     - Дождаться динамической загрузки элементов личного кабинета.
   - **Результат**: Отображение главной страницы профиля с проектами пользователя.

   - **Название теста**: `Авторизация на сайте YouGile через вкладку VK.`
   - **Описание теста**: `Тест проверяет авторизацию при помощи стороннего сервиса VK ID.`
   - **Шаги теста**:
     - Открыть страницу сайта по ссылке.
     - Нажать на иконку VK.
     - Переключиться на новое открывшееся окно VK ID.
     - Ввести учетные данные (телефон/email и пароль) из файла `.env`.
     - Нажать на кнопку Войти и вернуться в исходное окно YouGile.
   - **Результат**: Отображение главной страницы профиля с проектами пользователя.

   - **Название теста**: `Добавление нового отдела.`
   - **Описание теста**: `Тест проверяет возможность добавления нового отдела в мою компанию.`
   - **Шаги теста**:
     - Перейти в настройки аккаунта по прямой ссылке с использованием активной сессии авторизации.
     - Перейти во вкладку "Моя компания" -> "Отделы компании".
     - Нажать на кнопку "Добавить отдел".
     - Заполнить обязательные поля формы.
     - Нажать на кнопку "Создать отдел".
   - **Результат**: Новый отдел отобразился в списке "Отделы компании".
  
   - **Название теста**: `Редактирование названия отдела.`
   - **Описание теста**: `Тест проверяет возможность редактирования названия отдела.`
   - **Шаги теста**:
     - Перейти в настройки аккаунта (сессия уже активна).
     - Проскроллить страницу до нужного отдела из списка.
     - Нажать на кнопку "Редактировать".
     - Очистить старое название и ввести новое.
     - Нажать на кнопку "Сохранить изменения".
     - Явно дождаться визуального исчезновения старого названия с экрана.
   - **Результат**: В списке отделов отображается отдел с новым названием.
  
   - **Название теста**: `Удаление существующего отдела.`
   - **Описание теста**: `Тест проверяет возможность удаления существующего отдела.`
   - **Шаги теста**:
     - Перейти в настройки аккаунта (сессия уже активна).
     - Найти целевой отдел в списке.
     - Нажать на кнопку "Удалить отдел".
     - Подтвердить удаление в появившемся модальном окне.
     - Дождаться полного исчезновения элемента с экрана с помощью динамических ожиданий.
   - **Результат**: Удаленный отдел гарантированно не отображается в списке.
